## Reproduce

```bash
npm ci
npm run check
npm run format:check
npm run dev
# Configure a model in TrueForge Settings.
npm run eval:live
```

Live evaluations consume provider credit. They deny export automatically; test successful approval through the frontend. This is a local single-user application, not an internet-facing deployment. No hackathon video or submission form is generated by these checks.
