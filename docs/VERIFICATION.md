Each run executed at least three distinct successful MCP tools. Native sandbox output included parsed hostnames, URL counts, and a SHA256 fingerprint. Live IDs stay in ignored `.data/live-eval-summary.json`; no provider keys are included.

A separate bank investigation was submitted through the custom frontend. Its native approval pause survived a browser refresh and a TrueForge process restart. The download endpoint returned HTTP 403 before approval. Clicking Allow export resumed the harness, completed the case, and exposed a JSON download matching the local export artifact with the synthetic phone number redacted. The browser received the download event.

TrueForge can record direct MCP calls or a native `call_tool` dispatcher. Both forms were approved through the frontend and completed without relaxing the case/server/tool/argument approval binding. Regression tests and an independent authorization review cover malformed and cross-case wrappers. The populated bank report was visually inspected at 1280×900; the injection report's exact-argument approval card and controls were inspected at 375×812.

An initial invalid credential produced HTTP 401 and was replaced externally. The app recovered without code changes or secret copies. Failed-session restoration was also verified. External DNS/RDAP failures are retained as unknown observations.

## Reproduce

```bash
npm ci
npm run check
npm run format:check
npm run dev
# Configure a model in TrueForge Settings.
npm run eval:live
```

Live evaluations consume provider credit. They deny export automatically; test successful approval through the frontend. This is a local single-user application, not an internet-facing deployment. No hackathon video or submission form is generated by these checks.
